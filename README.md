Organizy is a small Python utility created by a teenager to organize your downloaded files and images into your Documents folder.
If you encounter any bugs or issues, feel free to report them or fix them yourself! :]
(The code was largely generated by AI as I am still learning).

## Features
* **[file exe]** - Automatically isolates main loose executables.
* **[extracted folders]** - Detects and stores already unpacked folders.
* **[non-extracted folders]** - Safely groups compressed archives (`.zip`, `.rar`, `.7z`).
* **[photos]** - Detects, handles, and automatically splits `.png`, `.jpg`, and `.jpeg` images.
* **[video mp4]** - Dedicated container for media files.
* **Smart Restoration (Restore System)** - A built-in safe back-track routine to undo sorting and return files back to their exact original system directories (including `Downloads` and `Pictures`) with a single click.

## How to Run
1. Make sure you have **Python 3.x** installed on your system.
2. Clone or download this repository.
3. Open your terminal or command line inside the directory and run:
   ```bash
   python organizy.py
   ```
4. Check the options boxes, press **Apply** to sort your files, or **Restore** to backtrack everything!
